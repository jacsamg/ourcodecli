# Ourcodecli 🎒

CLIs personales para Node.js

## Paquetes

- [@ourcodecli/copy](https://github.com/jacsamg/ourcodecli/tree/main/packages/copy)
  - CLI para copiar archivos y directorios
- [@ourcodecli/delete](https://github.com/jacsamg/ourcodecli/tree/main/packages/delete)
  - CLI para eliminar archivos y directorios
- [@ourcodecli/icon-generator](https://github.com/jacsamg/ourcodecli/tree/main/packages/icon-generator)
  - CLI para generar iconos PNG de PWA a partir de una sola imagen
- [@ourcodecli/material-symbols](https://github.com/jacsamg/ourcodecli/tree/main/packages/material-symbols)
  - CLI para generar subconjuntos self-hosted de Google Material Symbols
- [@ourcodecli/symlink](https://github.com/jacsamg/ourcodecli/tree/main/packages/symlink)
  - CLI para crear enlaces simbólicos a archivos o directorios
